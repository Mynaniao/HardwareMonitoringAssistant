# 硬件监控浮窗 说明书

## 一、功能简介

一个轻量级桌面悬浮窗，实时显示 CPU、内存、GPU、硬盘和帧率状态。

### 显示内容

| 行 | 显示项 | 说明 |
|---|---|---|
| CPU | 使用率 % + 温度 °C | CPU 占用百分比与核心温度 |
| MEM | 使用率 % + 已用容量 / 32GB | 内存占用百分比与已用内存 |
| GPU | 使用率 % + 温度 °C + 显存已用 / 12GB | 独显占用、温度、显存占用 |
| Disk | 总容量占比 % + 读写速度 + 硬盘温度 | 所有硬盘总容量、实时读写、硬盘温度 |
| FPS | 游戏内帧率 | 由 PresentMon 提供，仅在全屏游戏中有数 |

### 交互方式

- **左键拖拽**：移动浮窗位置
- **靠近屏幕边缘**：自动吸附（上下左右，不收入）
- **右键菜单**：锁定 / 解锁
  - 锁定后：鼠标左键穿透浮窗（无法拖动、无法点击），仅右键可用，方便玩游戏时不遮挡
- **双击**：无操作（预留）

### 视觉特性

- 半透明白色背景，圆角
- 深绿色字体
- 始终置顶（不强制每 2 秒重设，避免与全屏游戏冲突）

## 三、使用方法

1. 解压本压缩包到任意目录（中文路径也可以，程序内部已加引号处理）
2. 双击 **硬件监控.exe** 运行
3. 首次启动会自动拉起 HWiNFO64 和 PresentMon，无需手动操作
4. 浮窗出现在屏幕上，可拖到任意位置
5. 右键 → 锁定，玩游戏时浮窗不挡操作
6. 退出：右键浮窗 → **退出**（本程序没有托盘图标）

### 开机自启（可选）

将 **硬件监控.exe** 的快捷方式放入：
```
Win+R → shell:startup
```
即放入启动文件夹。

## 四、数据来源

| 数据 | 来源 |
|---|---|
| CPU 温度、GPU 温度、硬盘温度 | HWiNFO64 共享内存 |
| CPU/GPU/内存/硬盘使用率 | Windows 性能计数器（PDH） |
| 显存占用 | HWiNFO64 共享内存 |
| 硬盘读写速度 | Windows 性能计数器 |
| FPS | PresentMon（ETW 事件跟踪） |

### 为什么需要 HWiNFO？

Windows 自带的性能计数器读不到 CPU 和显卡温度（没有标准接口），HWiNFO 提供共享内存让本程序读取传感器数据。HWiNFO 以便携模式运行，不安装服务、不常驻，仅在浮窗运行时伴随启动。

### 为什么 FPS 有时候显示 --？

PresentMon 只在**全屏独占游戏**或使用 DirectX/Vulkan 的程序中能采集到帧率。桌面浏览、窗口化应用不会显示 FPS。

## 五、常见问题

**Q：CPU 温度和任务管理器不一样？**
A：任务管理器显示的是"封装温度"（一个均值），本程序从 HWiNFO 读取各核心温度，通常更准确。奥创中心和 HWiNFO 的读数也可能有 2-5°C 差异，属正常。

**Q：浮窗遮挡游戏怎么办？**
A：右键浮窗 → 锁定，鼠标穿透，然后把它拖到屏幕角落。

**Q：HWiNFO 弹窗怎么办？**
A：HWiNFO64.INI 已预设为静默共享内存模式，正常不会弹窗。如果弹窗，关闭 HWiNFO 窗口即可，传感器数据仍在后台读取。

**Q：换一台电脑能用吗？**
A：可以。解压即用，无需安装。但需要目标电脑：
- Windows 10 64 位或以上（.NET Framework 4.8，Win10 1903+/Win11 已内置，**无需另外安装**）
- NVIDIA 显卡的 GPU 温度读数需要 NVIDIA 驱动

**Q：风扇转得很响？**
A：浮窗本身 CPU 占用 < 1%，不影响性能。风扇响是游戏或其他程序导致的，与浮窗无关。

## 六、技术细节

- 开发语言：C#（.NET Framework 4.8 / WinForms）
- 编译方式：内置 `csc.exe` 直接编译成单文件 exe（见仓库 `build.ps1`，无需安装 SDK）
- 数据刷新间隔：2 秒
- HWiNFO 共享内存读取频率：2 秒
- PresentMon 采样：后台进程，每秒汇总帧率
